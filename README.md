# Muevo León Rush

A hybrid rhythm and driving game where you take on the role of a bus driver racing to reach each stop on time.

Follow the rhythm of the music, dodge traffic, keep your passengers happy, and avoid causing accidents.

Developed with **Unity 6.1** , **C#** and **Arduino**.

## Gameplay

Muevo León Rush combines rhythm-based gameplay with driving mechanics. The player must navigate through traffic while keeping up with the rhythm of the music and reaching to the end.

The game can be played using traditional controls or an optional Arduino-based steering wheel with physical buttons.

### Features

* Rhythm-based driving gameplay
* Bus driving
* Dynamic road sections
* Vehicle physics
* Multiple input methods
* Optional Arduino steering wheel support

## Technologies

* Unity 6.1
* C#
* Unity Input System
* Arduino

The original project also includes game assets and resources used during development, while this repository is organized to keep the source code accessible and easy to explore.

## Development

Muevo León Rush is a game development project created to explore gameplay programming, vehicle systems, rhythm-based mechanics, and different approaches to player input.

The project also served as an opportunity to experiment with physical hardware by integrating an Arduino-based steering wheel as an optional input device.
